# 最佳化專業主線：教材執行計畫

建立日期：2026-09-06。目標讀者：具微積分、基礎力學與少量 Python 經驗，希望以肌肉骨骼逆問題與最佳化方法為核心專業的博士生。

## 目標與教學原則

讀者最終應能定義問題、分析可行性與解的性質、推導最適條件、實作和修改演算法、驗證數值結果，並區分資料證據與選解假設。最佳化作為貫穿全書的主線；不以會操作單一軟體作為畢業標準。

同一個小模型反覆出現，每次增加一個概念。每個主要概念從生物力學、幾何、代數、演算法、統計、科學推論六個角度建立連結；六個角度分階段引入，不在第一課塞入全部內容。深入推導保留中間步驟，動畫與靜態圖使用同一份數據。

## 分期交付與驗收

| 期別 | 核心問題 | 內容與成果 | 通過標準 |
|---|---|---|---|
| P1 | 同一力矩為何有不同肌肉答案？ | 兩條同向肌、可行線段、零空間、兩種平方目標、上限與不可行案例 | 手算與解析程式、SLSQP 一致；動畫顯示選解差異 |
| P2 | 如何定義最好？ | 尺度、權重、活化與力、目標比較、Pareto 圖解 | 能說明權重與單位影響；能辨別偏好與證據 |
| P3 | 為何解停在這裡？ | 梯度、Hessian、凸集、嚴格凸性、存在與唯一性 | 手推與圖形互證；提出非唯一反例 |
| P4 | 約束如何改變解？ | Lagrange 乘子、KKT、互補鬆弛、活躍集合與敏感度 | 計算可行性、平穩性與互補殘差；解释乘子的條件與符號 |
| P5 | 電腦如何找解？ | 梯度法、Newton、線搜尋、投影、尺度與條件數 | 手寫小型求解器，和成熟求解器比較；診斷壞梯度與病態問題 |
| P6 | 資料不完美怎麼辦？ | 最小平方、正則化、雜訊、可辨識性、SVD | 區分唯一估計與可辨識性；用合成真值評估偏差與穩定性 |
| P7 | 真實肌肉模型帶來什麼難題？ | 非線性、非凸性、初值、導數驗證、模型誤差 | 多初值比較；不把局部收斂宣稱為全域最適 |
| P8 | 整段動作如何一起最佳化？ | 狀態與控制、動態約束、直接配點、網格細化 | 動態缺陷與網格收斂檢查；前向重播驗證 |
| P9 | 如何形成方法專業？ | 選定生物力學問題，修改方法並重現基準 | 提交假設、推導、程式、基準、消融與限制完整報告 |

## 第一個可交付單元

放置於 `06_optimization/`，對應既有 Stage 6，但第一課只依賴單關節力矩與基礎代數。保持既有教材目錄與 Stage 編號。

合成模型：$0.04F_1+0.02F_2=8$ N·m，$0\le F_1\le300$ N、$0\le F_2\le100$ N。先推導所有可行解，再比較最小力平方和與最小正規化活化平方和。明示固定姿態、固定力臂與 $F_i=a_iF_{i,max}$ 的簡化，不把它宣稱為完整 Hill 模型或真實神經控制策略。

檔案包括總覽、逐步筆記、已執行 notebook、可重用解析模型、動畫、練習與參考解、測試。動畫一比較目標權重造成的選解移動；動畫二增加需求力矩直到肌力上限使問題不可行。靜態圖保留初始、邊界與不可行狀態。

## 驗證與研究訓練

計算檢查包含手算數值、力矩平衡、上下限、解析解對成熟求解器、活躍上限、零需求、恰好最大能力與超出能力。不可行時明確報告無解，不畫出虛假的最佳點。

後續單元逐步增加 KKT 殘差、有限差分導數核對、迭代軌跡、條件數、擾動分析與網格收斂。每課至少一個故意失敗案例；每課作業依序為重現、改假設、設計方法。動畫不是驗證證據，必須與數值檢查分開。

## 動畫擴充

P1 顯示力平面、可行線段、等高線、最佳點與力矩殘差。P3/P4 加入梯度、約束法向量與 KKT；P5 加入迭代點與停止準則；P6 顯示雜訊造成的解分布；P8 顯示時間節點與動態缺陷。每個動畫提供暫停、逐格與靜態替代，依 `ANIMATION_GUIDE.md` 維護。

## 來源

理論骨架採 Boyd & Vandenberghe 的 [Convex Optimization](https://web.stanford.edu/~boyd/cvxbook/index.html)，依問題重新編排。實務銜接參考 [OpenSim 靜態最佳化說明](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53089624/Getting%2BStarted%2Bwith%2BStatic%2BOptimization)。來源支持理論與工具背景；教學合成數值、動畫及練習由本專案建立。
